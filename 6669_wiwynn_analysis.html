規則一・A逐年趨勢｜暴衝暴跌型

營業活動現金流(A)近12年呈現劇烈鋸齒狀擺盪，而非穩定成長：2021年 -142億 → 2022年暴增至 307億 → 2023年 231億 → 2024年又轉負 -200億 → 2025年雖轉正但僅 -6.24億（仍為負值）→ 26Q2單季更惡化至 -616億。近5個完整年度（2021-2025）中有3年為負值，且最新單季狀況是全期最差紀錄，看不出中長期方向感，屬於「賺多賺少全憑那一季」的暴衝暴跌型公司，而非穩健成長型。

規則二・B投資紀律｜敢衝且規模擴大型

B持續為負值且投資規模逐年放大：2019年僅 -6.72億，到2025年已達 -138億，成長超過20倍。緯穎屬伺服器/AI伺服器代工（資本密集）產業，持續大規模資本支出屬合理現象，不宜過度扣分，但規模擴張速度值得留意是否已超出本業造血能力（見規則四）。

規則六・E期末餘額穩定性｜體質增厚型

期末現金餘額（2018-2025）呈現強勁且持續的上升趨勢：14 → 120 → 232 → 227 → 262 → 375 → 483 → 899億元，僅2020→2021出現約2%的小幅回落，其餘年度皆持續墊高，2024→2025更是大幅成長86%。儘管營業活動現金流本身波動劇烈（規則一），公司整體現金儲備仍不斷增厚，這與規則四揭露的「持續對外融資」直接相關——現金餘額的成長有相當部分來自外部資金挹注，而非單純本業造血累積，解讀時不宜只看這條規則就認定「體質很好」。

⚠ 現金流體質偏弱／有風險訊號

六大規則平均分數為 53%，未達60%的「可繼續」門檻。更關鍵的是，「A為負＋B重度投資＋C為正/小幅負值」的三重疊加最高警戒訊號在12年半的資料中反覆出現5次（2016、2018、2021、2024、26Q2），且最新一期規模最大，顯示本業造血能力與外部資金依賴的緊繃關係並非偶發，而是這檔股票的結構性特徵。
